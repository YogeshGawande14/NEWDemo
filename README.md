# 📂 Demo Repository - Understanding GitHub

This repository is created solely for the purpose of learning, testing, and understanding how Git and GitHub work together. 

---

## 🔍 What is this repository for?
* **Experimentation:** A safe sandbox to test writing code, editing files, and making mistakes without breaking a real project.
* **Workflow Practice:** Testing out commands like `git add`, `git commit`, and `git push` to see how changes move from your computer to GitHub.
* **Version Control Demo:** Understanding how Git keeps track of history and saves different versions of your work.
